# OptCulture Sales Docs – User Guide (Sales)

**Open the app:** use the bookmark/link shared by Amith and sign in with your @optculture.com Google account.

## Create documents for a deal (5–10 minutes)
1. **New Deal → 1 · Client.** Type the client's legal name (or pick an existing client), choose the **country**: market, currency and the contracting OptCulture entity / partner fill in automatically. Add contacts and the client signatory.
2. **2 · Commercials.** Stores, e-commerce sites, packages to quote, add-ons and optional services. Leave special prices empty for standard pricing. Fill the Order Form terms (package, term, start date, billing).
3. **3 · Documents.** Tick the documents you need and the language. Type 3–4 lines about the client and click **✨ Draft with AI** → review and edit the summary and journeys.
4. **4 · Review.** Check prices and the "Missing information" list. Add a note for Amith if you used a special price. Click **Generate documents**.

The **Live summary** on the right shows prices, approval need and missing items while you type. Click **Save draft** at any time.

## What happens after Generate
- **Standard pricing:** final Google Docs + PDFs are created in the Shared Drive, shared with you and your manager, and emailed to you.
- **Special price below standard:** DRAFT documents (red banner, no PDF) are created and Amith is asked to approve. Do **not** send drafts to the client. When Amith approves, final PDFs are created automatically and you get an email. If he rejects, read his comment, edit the deal and generate again.

## My Deals
Search and filter your deals; **Open** to continue or revise (revisions become v2, v3… with the same document numbers); **Clone** to start a similar deal; mark **Sent / Won / Lost** after sending documents.

## Good to know
- Prices come from the master price list and are frozen when you first save a deal. Tick "Use today's price list" (step 2) to update.
- Never edit prices inside the generated Google Doc. Change the deal and generate again, so approvals and records stay correct.
- Questions or errors: contact Varaprasad; screenshots help.
